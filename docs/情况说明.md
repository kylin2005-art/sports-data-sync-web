# 项目情况说明

Sports Data Sync Web 用于在运动平台之间同步活动，也能把 FIT / GPX 原件保存在自己的电脑或 NAS。支持 Windows 本机运行和 Docker Compose 部署。Docker 个人版在首次访问时创建账号，邀请制工作区按账号保存任务、连接、文件和回执。

登录 Docker 工作台后，系统会检查已保存的平台连接。能读取的平台使用活动接口验证，佳明在需要时通过现有授权续期。页面会区分登录有效、需重新连接、暂无法核验和使用时校验。仅支持上传的平台会在首次实际使用时检查授权。

首页同步目标只显示当前可选择的连接和本机文件。创建定时任务或追加目标时，需要先连接目标平台。旧任务已保存的目标即使掉线也会保留，可以在编辑时移除。来源就绪且仍有可用目标时，可手动同步这些目标，定时任务继续按原配置等待其余连接。

任务支持首次全量扫描和后续增量。已确认的活动会按回执去重。上传结果不明时会保留待核对状态，避免重传。已有活动 ID 的佳明回执可在记录中心按原目标账号回查。运行日志用绿色标出成功、红色标出错误、琥珀色标出待核对，并给出相应处理提示。

新建任务也可独立选择「仅增量」。平台来源按启用后的活动开始时间判断，本机文件按导入时间判断。平台时间无法确认的记录会跳过，已有回执和失败重试规则继续生效。

已保存的任务支持暂停和恢复。暂停时会停止该任务的自动运行，也会禁用立即同步。正在运行的任务会在当前请求结束后停止，已发出的上传仍会核对结果。重启后保留暂停状态，恢复时按原间隔安排下一次运行。

行者活动列表会留出分页间隔。后续页遇到 HTTP 400 时，会稍等并重试原页一次，仍失败则显示分页位置。仅同步骑行时，按行者返回的运动类型识别骑行、骑行台、室内骑行和电助力骑行。

轨迹工具支持表格浏览、真实地图、速度或功率着色、3D 海拔轨迹和骑行战报。战报可导出 PNG。地图瓦片在主动加载地图时由浏览器请求。

骑行轨迹支持按日期、距离、累计爬升、均速和平均功率组合筛选。筛选先查询整个工作台存档，再分页。历史轨迹摘要存入工作台 SQLite，首次筛选补齐旧文件，后续只计算新文件，重启后也可复用。

「分享图」主题库收录 24 套版式，每套都支持自定义主标题。选择活动后可用本人存档预览和导出标准 1080 × 1224 PNG，或抖音 9:16 的 1080 × 1920 PNG。缩略图使用示例数据。也可从同路线对比、年度高光和月度明信片直接打开对应主题。首次打开月刊或日历时，会补齐尚未索引的骑行，随后复用年度高光索引。月历会包含实际骑行日。

图库默认隐藏路线和单次日期。显示路线时可使用完整轮廓或裁去起终点附近。部分地图、地形与插画是示意背景。合照和手账笔记按需选入，合照只在当前浏览器里处理。缺失的指标以「—」显示，估算值带「≈」。旧版 3:4 和 9:16 战报也可继续使用。

[查看 24 套主题效果图](使用说明.md#24-套分享图主题效果)

带标准 GPS 路线的活动可以从单次骑行分析收藏。每条手账可保存路线名、标签、补水点和路况，在轨迹工具中按标签筛选或打开原骑行。手账随工作台数据卷备份，取消收藏后原活动仍可查看。

勾选两条活动可做同路线骑行对比。在工作台内叠加路线示意图和海拔曲线，查看两趟的用时、距离、爬升和传感器指标。只有轨迹判为同方向且用时口径一致时才显示快慢差值。方向判断基于定位轨迹估算。

「自动骑行月报与进步分析」打开即按浏览器时区汇总所选月份。月报使用当前工作台的完整 FIT / GPX 存档，显示骑行次数、天数、里程、爬升、运动计时、经过时长和新探索格子。两月各自按已入库的数据统计。进步分析为当月每趟骑行寻找最近一次同方向、同计时口径的历史活动，显示用时变化和两趟都有的传感器差值。功能免费，新增实现与测试采用 [MIT 许可](../LICENSE-RIDE-REPORT)。

月报摘要随工作台 SQLite 数据卷保存。首次打开会补齐旧档案的摘要，之后只解析新入库的文件。新探索格子复用现有格子索引，按当月首次覆盖的历史新格子计算。报告在本机生成，无需连接运动平台或请求地图瓦片。

月报已在 Unraid 内网版 `0.3.0+18ca3d0` 用现有活动存档验收。已核对月度汇总和一组实际同路线活动，重启后仍能复用已生成的摘要。大型存档的首次建索引会比日常读取花费更多时间。

打开单次活动的「骑行探索」，可用当前工作台已保存的 FIT / GPX 查看本次新增格子和此前骑过的区域。格子由原始定位点计算，同一格只计一次。活动按文件或来源活动时间排序，缺少时间时按存档先后判断。无 GPS、明确标为其他运动或坐标系不兼容的文件不计入。未标运动类型的 GPX 会按 GPS 轨迹计算。探索卡可下载或分享 PNG，只含格子统计。

探索格子索引保存在各工作台的 SQLite 数据库里，随数据卷备份和恢复。升级后会为存量文件建一次索引。此后打开探索地图时，只解析尚未建立索引的新文件，重启后继续使用原索引。

「年度骑行高光」从有活动日期的 FIT / GPX 中找出年度最长距离、单次最高爬升、单次覆盖格子最多的骑行，以及最高连续 5 分钟平均功率。室内 FIT 的距离和功率可参与排名。功率区间须有连续采样，缺失时不生成纪录。年度摘要会保存到工作台数据库。

「轨迹工具」的月度骑行明信片直接使用格子索引。按浏览器时区汇总每月骑行，展示经过频率热图、单次覆盖最多的代表骑行，以及它与当年此前月份纪录的比较。分享图默认只显示月份和统计，可选加入裁剪后的代表路线轮廓。真实热图在工作台内查看。

升级 Docker 部署时，保留原数据卷、加密密钥和 HTTPS 配置。先备份再更新。Windows 本机版继续使用原 Windows 用户及应用数据目录。

Unraid 的 Docker 本地卷若通过 `bind` 指向实际数据目录，容器停止后应备份卷配置中的 `device` 目录。切换镜像前，核对归档包含账号数据库、工作区数据库和加密凭据文件，再校验归档内容及 SHA-256。
